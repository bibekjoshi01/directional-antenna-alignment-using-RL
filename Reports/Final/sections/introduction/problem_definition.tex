\subsection{Problem Definition}

Current reinforcement learning methods for antenna alignment have been developed with applications mainly focusing on the mmWave beamforming system or antenna array or similar systems where a lot of computational power is available. As a result, there is a gap left when it comes to developing low cost methods for embedded devices with antenna alignment that operates based on RSSI readings. Moreover, classic algorithms like exhaustive scanning and hill climbing, although simple to design, are not suitable for solving the current task – exhausts scanning takes too long while hill climbing can be hindered by noise, multipaths and local maximum.

The main objective of this project is to fill this gap by formulating the problem as antenna alignment using only the received RSSI signal for making decisions and the internal antenna angle estimation as state space parameters. The algorithm should be implemented on an ESP32-S3 with low computational power, memory and energy while using only a mechanically steerable antenna without any phased arrays, GPS, AOA and propagation model. Therefore, this project explores the possibility of running the tabular reinforcement learning algorithm on an embedded device.
